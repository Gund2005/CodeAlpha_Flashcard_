# CodeAlpha Flashcard Quiz App

## About
This project is a Flashcard Quiz App developed as part of the CodeAlpha Internship – Task 1.

The application helps users study using question-and-answer flashcards.

## Features

- 15 pre-added flashcards
- Show Answer feature
- Next and Previous navigation
- Question counter
- Add new flashcards
- Edit existing flashcards
- Delete flashcards
- Simple and clean user interface

## Technologies Used

- Python
- Tkinter

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
py app.py
